# GitHub Achievement Checklist

Use this checklist to track genuine activity. GitHub awards achievements automatically; editing this repository or its README does not unlock badges by itself.

## Actions you can work toward

- [ ] **Quickdraw** — close a genuine issue or pull request quickly when it has actually been resolved. Avoid opening throwaway issues just for a badge.
- [ ] **YOLO** — merge a useful pull request without a review when review is not required by repository rules.
- [ ] **Pull Shark** — get useful pull requests merged; higher tiers require more qualifying merged PRs.
- [ ] **Pair Extraordinaire** — collaborate with another developer on a merged pull request with qualifying co-authored commits.
- [ ] **Galaxy Brain** — provide helpful answers in a repository's Discussions; the author must mark qualifying answers as accepted.
- [ ] **Starstruck** — grow a useful project organically until it reaches the qualifying star count.
- [ ] **Public Sponsor** — sponsor an eligible open-source maintainer through GitHub Sponsors if you genuinely want to and can afford it.

## Not a shortcut

- A README badge image does not grant an official profile achievement.
- Do not buy stars, spam issues, arrange fake accepted answers, or manufacture low-quality collaboration.
- Historical achievements such as Arctic Code Vault Contributor and Mars 2020 Contributor are tied to past events and are not normally available to earn now.

## Verify status

Open your GitHub profile, find **Achievements**, and select a badge to see its details and qualifying event links. Check the official documentation because eligibility and tiers may change:

- https://docs.github.com/en/account-and-profile/reference/profile-reference
- https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference
