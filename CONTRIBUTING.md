# Contributing

Thanks for helping improve this GitHub Achievements guide.

## How to contribute

1. Open an issue describing the factual correction, missing achievement, or documentation improvement.
2. Link an official GitHub Docs page or another reliable primary source when changing eligibility details.
3. Keep achievement instructions honest and reproducible. Do not recommend fake stars, self-accepting answers, spam issues, or artificial collaboration.
4. Make focused changes and explain what changed in the pull request.
5. Check that links work and that historical or experimental achievements are clearly labeled.

## Pull requests

- Use a descriptive title.
- Explain why the change is useful.
- Include source links for requirements that may change.
- Keep unrelated edits out of the same pull request.

## Reporting an issue

Please include the achievement name, the requirement you believe is inaccurate, a source link, and the date you checked it.
